# TaskManager

A task manager backend built with Spring Boot and MySQL. The project is focused on building a REST API and practicing CRUD operations, JPA, and database relationships.

# Features
Create, read, update, and delete tasks
User registration and login
User roles
MySQL database
JPA / Hibernate
Request validation
DTOs for API requests and responses

# Tech Stack
Java
Spring Boot
Spring Data JPA
Hibernate
MySQL
Lombok
Maven
